Structure version: 20261026.02

Layout rules for this repository. The README describes the same directories
for a reader; this file is the rule.

patches/            numbered patches on top of the upstream commit that
                    packaging/upstream.lock pins (patjak/facetimehd c9b063a).
                    0001-0004 are upstream PR #355, 0005 on are this
                    project's. Exported from build/dev with
                    `git format-patch --zero-commit`; every patch is pinned by
                    SHA256 in the lockfile, and a patch it does not list is
                    refused.
src/macbook91-facetimehd/
                    the DKMS tree. Generated by packaging/fetch-upstream.sh
                    from the lockfile, patches/ and packaging/overlay/, and
                    gitignored: no driver source is maintained here outside
                    patches/. fetch-upstream.sh writes SOURCES.sha256 over the
                    tree, and the module Makefile refuses to build from a tree
                    that does not match it.
packaging/          fetch-upstream.sh, mkdist.py (reproducible source
                    tarball), promote-release.sh, make-package.sh (wrapper for
                    `make arch-pkg-dev`), upstream.lock (tracked: the
                    provenance record, promoted into release/<pkgver>/).
packaging/overlay/  the module Kbuild, Makefile and dkms.conf that replace
                    upstream's Makefile and dkms.conf in the assembled tree,
                    and TESTED-SERIES: the one list of kernel series (X.Y)
                    the driver is tested on. DKMS builds for every kernel;
                    a series joins the list only after a verify PASS on it.
packaging/arch/     PKGBUILD (macbook91-facetimehd-dkms), .SRCINFO and the
                    install scriptlet. Not part of the source tarball, which is what
                    lets the PKGBUILD pin the tarball's checksum.
Makefile, VERSION   the package contract: `make dist` writes
                    dist/NAME-VERSION.tar, `make install`
                    is what the driver package runs from it, `make
                    arch-pkg` builds a release against the pinned checksum,
                    `make check` runs the tests. VERSION is the single
                    version, YYYYMMDD.NN; pkgver and the release tag
                    v<VERSION> must equal it.
LICENSE, LICENSES/  LICENSE is the GPL-3.0 text (same file as
                    LICENSES/GPL-3.0-or-later.txt): this project's own files are
                    GPL-3.0-or-later, except the files that build or install
                    the module (packaging/overlay/): GPLv2 section 3 makes
                    them part of its source, so they are GPL-2.0-or-later.
                    LICENSES/<SPDX-ID>.txt holds every other license in use:
                    GPL-2.0-only (upstream driver, patches/, the firmware
                    extractor), GPL-2.0-or-later (packaging/overlay/). Every own file
                    with comment syntax starts with an SPDX-License-Identifier
                    line, after the shebang if there is one; README.md
                    "Provenance and licensing" maps every path. A new license
                    needs its text in LICENSES/ and a row in that table.
tools/              macbook91-facetimehd-verify and macbook91-facetimehd-fetch-firmware
                    are packaged to /usr/bin. macbook91-facetimehd-kernel-series
                    (the only reader of TESTED-SERIES) is packaged to
                    /usr/lib/macbook91-facetimehd/kernel-series, and
                    macbook91-facetimehd-series.hook, the pacman hook that
                    calls it, to /usr/share/libalpm/hooks/ as
                    71-macbook91-facetimehd-series.hook. dev-*.sh
                    are development helpers for the maintainer's test machine
                    and are not packaged.
tests/              run-tests.sh: hermetic, no root, no hardware. Hardware
                    checks are listed as BLOCKED and recorded in
                    docs/test-status.json when run on the test machine.
release/<pkgver>/   the current release: PKGBUILD, .SRCINFO, source tarball,
                    install scriptlet, upstream.lock, STATUS.txt and
                    SHA256SUMS exactly as published. The built driver package
                    is not tracked and not one of these files.
                    promote-release.sh prunes older release directories;
                    they are not part of this repository.
                    Apple's firmware is never here and never a release asset:
                    the user downloads it with
                    tools/macbook91-facetimehd-fetch-firmware.
docs/               research, hardware facts, options, plan, design
                    (POWER-RECOVERY.md), measurements, changelog, test
                    status. Every claim is tagged VERIFIED / NOT VERIFIED /
                    REFUTED.
docs/diag/          sanitized diagnostic excerpts: system output and short
                    excerpts of Apple's ACPI tables, quoted for
                    interoperability research (no serials, no LUKS UUIDs,
                    no MAC addresses).
dist/, build/       gitignored output: tarball, packages, makepkg work area
                    build/arch (recreated for every build), the upstream clone
                    build/upstream and the development tree build/dev.

Paths that exist only in the maintainer's own checkout (agent configuration,
local evidence, code-graph caches) are not part of the published tree and are
not described here.

Never tracked anywhere: Apple binaries (firmware.bin, *_01XX.dat,
AppleCamera*), serial numbers, MAC addresses, SSIDs. tests/run-tests.sh
checks the tracked files for firmware and MAC addresses.

Renamed on 2026-10-13 from facetimehd-macbook91; the module was facetimehd
until patch 0011.
